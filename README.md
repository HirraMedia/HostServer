# CraftVault – Minecraft Server Hub

    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt
    python app.py

Mở http://127.0.0.1:5000  (tài khoản đầu tiên đăng ký sẽ là Admin).
Cho máy khác trong mạng LAN vào: `set HOST=0.0.0.0` rồi chạy lại.
Dữ liệu nằm trong thư mục `data/` (database + file plugin).
